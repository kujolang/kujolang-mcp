How to interpret this

Calls and initializations are not unique people. Empty search results identify coverage gaps; nonempty results do not prove relevance or task completion. Topics use simple rules and can be wrong. Errors cover dispatched initialization/tool calls, not rejected HTTP traffic. Latency measures dispatch, excluding network and database time. Opt-outs, quota limits and analytics outages can cause undercounting. Compare revisions alongside traffic changes before attributing an improvement.
