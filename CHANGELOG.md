# Changelog

## 0.2.0 — 2026-10-23

Hardened preview: bounded Worker body streaming and JSON parsing, strict native configuration, shared native quotas, catalog identity validation, native/Worker numeric and Unicode parity, compact deterministic search results, pinned generation inputs and release evidence. Unknown config keys and decimal/exponent request IDs now fail explicitly. Tool integer arguments accept whole numeric values. Requires Kujo 1.9.0 or later; the upstream decimal precision fix is tracked separately from the hosted JavaScript Worker.

## 0.1.0 — 2026-10-22

First tagged preview release of the read-only Kujolang ecosystem catalog server, including native HTTP and Cloudflare Worker implementations, catalog provenance, seven tools, six resources and three prompts. Preserves the documented protocol, configuration and operational boundaries.
