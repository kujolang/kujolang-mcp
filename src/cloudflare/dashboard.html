How to use this

Prioritize popular catalog areas with empty searches or errors. Item and installation-profile requests indicate interest, not actual installation or use of downstream Kujo projects. Calls and initializations are not unique people. Nonempty results do not prove relevance or task completion. Topic classification is approximate. Dispatch latency excludes network and database time. Opt-outs, quotas and outages can cause undercounting; no raw queries or individual journeys are stored.

Telemetry notice

Charts use Dither Kit. Daily aggregate history is retained long-term, with private automatic backups. Cloudflare Access uses secure operator login cookies. Public catalog analytics uses no tracking cookies or browser storage.
